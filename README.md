# Beauty Business Template

Премиум responsive шаблон за козметични салони и естетични центрове.

## Идея
Това е master шаблон. За всеки нов клиент се прави отделно копие/repository и се сменят бранд, текстове, услуги, контакти, снимки и домейн. Така основният шаблон остава чист и може да се подобрява постоянно.

## Публикуване с Vercel
1. Влезте във Vercel.
2. Add New → Project.
3. Import `djokatapetrov/beauty-business-template` от GitHub.
4. Framework Preset: Other.
5. Deploy.
6. След deploy може да се добави собствен домейн от Project Settings → Domains.

## Персонализация
Основните текстове са в `index.html`, а дизайнът е в `styles.css`.
